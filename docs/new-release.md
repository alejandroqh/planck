# Updating versioning for package managers and whatnot

- App metainfo: `extra/linux/io.github.alejandroqh.planck.metainfo.xml`
- macOS plist (`CFBundleShortVersionString`): `extra/macos/Planck.app/Contents/Info.plist`
- Rust: `Cargo.toml`
- Obviously changelog: `CHANGELOG.md`
- RPM spec: `planck.spec`
- Windows wix spec (`<Product [...] Version=X.X.X>`): `extra/windows/wix/planck.wxs`
